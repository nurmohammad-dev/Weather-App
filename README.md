# Weather App

Short professional description

## Features
- Search locations
- Current weather
- 24-hour forecast
- 7-day forecast
- Geolocation
- Celsius/Fahrenheit
- Shareable weather URL
- Local preferences
- Day/night weather-aware UI
- Reduced-motion support

## Tech Stack
- Vite
- React
- JavaScript / JSX
- Tailwind CSS
- React Router
- Lucide React
- Lottie React

## Getting Started

### Installation
npm install

### Development
npm run dev

## Production Build
npm run build
npm run preview

## Available Scripts

| Command | Description |
|---|---|
| npm run dev | Start development server |
| npm run lint | Run ESLint |
| npm run build | Create production build |
| npm run preview | Preview production build |

## Routes

| Route | Purpose |
|---|---|
| / | Search page |
| /weather?... | Weather dashboard |
